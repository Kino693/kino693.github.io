Privacy notice

Effective 29 October 2026. This notice covers the single-owner Plainly Wired local publishing workspace and this information website.

Google and YouTube data

With the channel owner's authorization, the workspace accesses the channel identifier, upload list, video metadata, processing and publication status, caption metadata and channel-level Analytics and Reporting data. It uses these to verify the intended channel, prevent duplicate uploads, upload and manage the owner's films, and prepare performance reports. It does not request monetary analytics, Gmail access or the owner's Google password.

The app requests the youtube.force-ssl and yt-analytics.readonly permissions. These permissions are used only for the described publishing and reporting functions. Google account data and analytics are not sold, used for advertising profiles, sent to a generative model, or used to train models.

Storage and retention

OAuth tokens are stored locally using Windows DPAPI encryption for the current Windows user. The Gemini key is held separately in a local environment file. Episode media, source notes, receipts and reports are stored on the owner's computer. Portable project packages exclude credentials, live upload-session addresses and the live account database. These working records remain until the owner removes them; there is no public account-data database operated by this project.

Original media and AI services

The workspace can send the owner's original script to Google's Gemini API for synthetic narration and source-compatible original audio for quality review. Those media requests are separate from the YouTube account grant. Under Google's unpaid-service terms, submitted content may be used by Google to improve its products and machine-learning technologies. Media whose licence prohibits such reuse must not be sent through that route. The workspace does not send OAuth tokens, API keys or private YouTube analytics as model content.

Sharing

Finished media and chosen metadata are sent to YouTube. A private upload remains governed by YouTube's privacy settings; a public release makes the selected video and public metadata available to viewers. The owner's authorized service providers process the submitted data under their own terms. This project does not sell personal data or provide account access to advertisers.

Control and removal

The owner can pause or stop new local work and revoke the app's access in Google Account connections. Revocation prevents further authorized API access; it does not automatically remove files already saved locally or videos already uploaded to YouTube. Those can be managed separately by the owner. To ask about data handling or removal, contact chefbruno111@gmail.com.

This website

This static information site has no sign-in form, analytics script, advertising or app-controlled tracking cookies. If published through GitHub Pages, GitHub processes visitors' network information, including IP addresses, for security as described in the GitHub Privacy Statement. External links are governed by the destination's privacy notice.

Plainly Wired's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. See also Google's Privacy Policy and Gemini API terms.
